# Text Summarization Project

A text summarization project with utilities for data preprocessing and model training.

## Documentation

- [StandardScaler Feature Names Warning - Solutions](docs/STANDARDSCALER_FIX.md) - How to resolve sklearn StandardScaler feature name warnings

## Getting Started

### Installation

```bash
pip install -r requirements.txt
```

### Common Issues

If you encounter the sklearn warning:
```
UserWarning: X does not have valid feature names, but StandardScaler was fitted with feature names
```

Please refer to our [detailed guide](docs/STANDARDSCALER_FIX.md) for multiple solutions.
